# 教程推荐策略与资源库 (Tutorial Recommendations)

> AI 生成学习笔记时，依据此策略推荐学习资源。优先使用 WebSearch 实时搜索，此处作为后备和搜索关键词库。

---

## 一、推荐优先级

1. **官方文档** — 最权威，适合深入学习
2. **中文教程平台** — B站、掘金、CSDN，适合中国人学习
3. **系统课程** — 菜鸟教程、MDN、freeCodeCamp
4. **技术博客** — 知名博主深度文章

## 四、推荐文案模板

AI 生成资源推荐时遵循以下格式：

```
## 推荐学习资源

1. **[平台] 资源标题**
   一句话描述（为什么推荐这个）
   <URL>

2. ...
```

每个知识点推荐 1-3 个资源，优先 B站视频 + 官方文档 + 经典博客。
