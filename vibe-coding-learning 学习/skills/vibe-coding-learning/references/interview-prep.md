# 面试准备扩展模块 (Interview Preparation)

> 仅当用户明确提到面试时触发（Mode 4）。基于用户已学内容生成个性化面试准备材料。

---

## 一、触发条件

| 用户说 | 触发模式 |
|--------|---------|
| "准备面试" / "面试怎么讲" | 生成面试话术 + 常见题 |
| "帮我模拟面试" / "来一次面试" | 互动模拟面试 |
| "后端面试问什么" | 按目标岗位过滤 |

---

## 二、面试内容生成规则

### 2.1 项目介绍话术

**30 秒版**（适用于"介绍一下你做过什么"）：
- 技术栈（1 句）
- 核心功能（1 句）
- 个人贡献点（1 句）

**90 秒版**（适用于技术面深挖）：
- 技术选型理由（为什么选这个框架/方案）
- 架构设计（分层、模块拆分）
- 遇到的难点和解决思路
- 后续优化方向

### 2.2 常见面试题生成

基于用户已学知识点卡片，生成以下类型问题：

| 题型 | 示例 | 适用场景 |
|------|------|---------|
| 概念解释 | "JWT 和 Session 的区别？" | 后端/全栈 |
| 技术选型 | "为什么用 bcrypt 而不是 md5？" | 后端 |
| 实践题 | "你做过的最复杂的组件是？" | 前端 |
| 安全题 | "如何防止 XSS 攻击？" | 全栈 |
| 场景题 | "API 请求突然变慢，怎么排查？" | 后端/DevOps |
| 比较题 | "Flexbox 和 Grid 的使用场景？" | 前端 |

### 2.3 薄弱点分析

对比 progress.md 中的"待学习"清单，生成：
- 当前已掌握 vs 目标岗位期望的差距
- 高频面试知识点中的空白项
- 建议优先补充的方向

---

## 三、模拟面试流程

### 启动

```
"开始模拟面试。我会从你学过的知识中随机提问 5 个问题。准备好了吗？"
```

### 流程

1. AI 从 `cards/` 中随机选 5 个知识点
2. 每次问 1 个问题，等用户回答
3. 评价维度：
   - ✅ 说对了什么
   - ⚠️ 漏掉了什么
   - 💡 可以怎么改进
4. 5 题结束后给出综合评分：
   - 知识点掌握度
   - 表达清晰度
   - 深度理解力
   - 建议重点巩固的方向

### 题目示例

```
Q1: 你在项目中用了 JWT 认证。请解释 JWT 的三部分结构，以及为什么不能用 JWT 存储敏感信息？

Q2: 你说你用了 bcrypt 做密码哈希。bcrypt 和 md5 有什么区别？为什么现代系统都用 bcrypt？

Q3: （情境题）如果用户反馈登录很慢，你会从哪些方面排查？
```

## 四、目标岗位面试侧重点

| 岗位 | 核心考察 | 面试重点领域 |
|------|---------|-------------|
| 后端开发(实习) | 语言基础、数据库、API 设计 | backend + database + security |
| 前端开发(实习) | HTML/CSS/JS、框架、工程化 | frontend + css + js |
| 全栈开发(实习) | 前后端协作、部署 | backend + frontend + devops |
| AI 应用(实习) | LLM、RAG、Agent | ai-ml |
| 测试开发(实习) | 自动化测试、CI/CD | testing + devops |
| 运维/DevOps(实习) | 容器化、CI/CD、监控 | devops + cloud |
