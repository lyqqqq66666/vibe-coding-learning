# 输出模板说明 (Output Templates)

> 定义每种产出物的格式标准。SKILL.md 引用此处规则，AI 生成时对照检查。

---

## 一、每日学习笔记 (Daily Learning Note)

**模板文件**：`templates/daily-learning-note.md`
**保存路径**：`topics/[project-name]/YYYY-MM-DD-[title].md`

### 必填板块

| 序号 | 板块 | 内容要求 |
|------|------|---------|
| 1 | 基本信息 | 日期、技术领域、AI 工具、任务描述 |
| 2 | 知识点归纳 | 3-8 个，每个含：定义、原理、代码位置 |
| 3 | 代码讲解 | 阅读顺序 + 逐段解读 + "为什么这样设计" |
| 4 | 易错点整理 | 表格：易错点 / 正确做法 / 常见错误 |
| 5 | 推荐学习资源 | 1-3 个，B站/官方文档/博客，带 URL |
| 6 | 下一步学习建议 | 3 个 TODO 项 |

### 格式规范
- 用中文写，技术术语首次出现附英文
- 代码位置用 `文件名` 第 N 行 格式
- 易错点表格至少 3 行
- 资源推荐必须带可访问的 URL

## 二、知识点卡片 (Knowledge Point Card)

**模板文件**：`templates/knowledge-point.md`
**保存路径**：`cards/[category]/[kebab-case-name].md`

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 标题 | 技术名称 | `# JWT 认证机制` |
| 标签 | 分类标签 | `auth`, `security`, `backend` |
| 一句话定义 | 15 字以内 | JSON Web Token，无状态认证协议 |
| 核心原理 | 2-4 句 | 签发→携带→验证 三阶段 |
| 工作流程 | 编号列表 | 1. 登录 2. 签发 3. 存储 4. 携带 5. 验证 |
| 常见误区 | 2-3 条 | ❌ 存储敏感信息 ❌ 不设过期 |
| 相关知识点 | 交叉引用 | OAuth 2.0, Session, Refresh Token |
| 首次提取 | 日期 + 项目 | 2026-06-11 / fastapi-auth |

### 复用规则
- 同一知识点多项目遇到时，更新卡片增加"出现项目"列表
- 不覆盖原有内容，只在末尾追加关联信息

## 三、学习日历 (Learning Calendar)

**保存路径**：`calendar/YYYY-MM.md`

### 格式

```markdown
# YYYY年MM月 — 学习日历

| 日期 | 主题 | 领域 | 知识点数 | 笔记链接 |
|------|------|------|---------|---------|
| 06-11 | FastAPI 登录注册 | 后端认证 | 7 | [笔记](topics/fastapi-login-register/...) |
```

---

## 四、进度总览 (Progress)

**保存路径**：`progress.md`

### 必含内容
- 统计数据（天数、领域数、知识点数、卡片数）
- 各领域进度（进度条 + 已学/未学清单）
- 最近学习（最近 5-7 天）
- 下一步建议（3-5 项）

---

## 五、HTML 输出（可选）

当用户指定 `preferred_format: html` 时：
- 内容同 Markdown 笔记
- 使用 `frontend-design` skill 生成精美页面
- 知识点卡片做成独立卡片样式
- 带目录导航和进度可视化
- 保存到同目录，文件名 `.html` 后缀
