# health-check — 知识健康诊断

## 目的

定期检测学习健康度，发现：
- 学了但忘了的主题
- 可以关联但未关联的知识
- 学习盲区（前置知识缺失）
- 学习疲劳（同一领域时间过长）

## 检查项

### 1. 遗忘检测

扫描笔记的 `last_review_date`，超过 `config.yaml` 中设置的天数（默认 30 天）未复习的主题：

```markdown
## ⚠️ 遗忘风险提醒

以下主题已超过 30 天未复习，建议尽快温习：

- `backend/auth/jwt-basics.md` — 最后复习：2026-05-20（32 天前）
- `frontend/react/lifecycle.md` — 最后复习：2026-05-18（34 天前）

💡 建议：用费曼学习法，试着不看笔记复述一遍。
```

### 2. 关联建议

检测同一时间窗口内学习但未建立关联的主题：

```markdown
## 💡 关联建议

以下主题在同一周内学习，但未建立关联，建议检查：

- `fastapi-login.md`（2026-06-18）
  ↕ 未关联
  `jwt-auth.md`（2026-06-19）

建议：在两篇笔记中添加双向链接。
```

### 3. 学习盲区检测

基于本周学习的主题，反向查找缺失的前置知识：

```markdown
## 🔍 学习盲区

你正在学习 FastAPI 异步接口，但检测到以下前置知识可能缺失：

- [ ] 异步编程基础（async/await）
- [ ] 事件循环原理
- [ ] Python GIL 对异步的影响

建议先补充这些基础，再深入 FastAPI 异步。
```

### 4. 学习疲劳检测

同一领域连续学习超过 7 天，建议切换：

```markdown
## 🔄 学习疲劳提醒

你已经在 `backend` 领域连续学习 10 天了，
建议切换到 `frontend` 或 `devops` 换换脑子。

💡 交叉学习可以提高长期记忆效果。
```

### 5. 笔记质量检查

检测内容过短或格式不规范的笔记：

```markdown
## 📝 笔记质量检查

以下笔记内容可能过短（< 200 字），建议补充：

- `temp_session_20260618.md` — 仅 150 字
  - 建议：补充代码示例和个人理解
```

## 报告格式

```markdown
# 知识健康诊断报告（2026-06-21）

## 健康评分：🟡 75/100

### 扣分点
- 🔴 -15：2 个主题超过 30 天未复习
- 🟡 -10：5 对主题未建立关联
- 🟢 -0：无学习盲区
- 🟡 -5：同一领域连续学习 10 天

## 优先处理（按紧急度排序）

1. 【紧急】复习 `jwt-basics.md`（遗忘风险高）
2. 【重要】建立 `fastapi` 与 `jwt` 的关联
3. 【建议】切换到 `frontend` 领域（疲劳风险）

## 长期改进建议

- 设置每周五为「复习日」，集中复习本周笔记
- 学完一个新主题后，立即检查与旧主题的关联
- 每 2 周做一次「知识盲区扫描」，补充前置知识
```

## 触发方式

```
用户说：
- "检查学习健康度"
- "我有没有忘记复习的"
- "知识诊断"
- "health check"

也可以配置为每周自动运行（如果 AI 工具支持 cron）
```

## 自动化建议

在 `config.yaml` 中配置：

```yaml
health:
  auto_run: true  # 每周自动运行
  auto_run_day: monday  # 每周一运行
  notification_method: chat  # 结果通知方式：chat / file
```
