# vibe-coding-learning 测试用例集

> 版本 1.1.0 测试用例 | 覆盖所有 9 个模式的触发边界

## 一、应触发测试（10 个）

| # | 输入语句 | 预期模式 | 预期执行策略 | 验证要点 |
|---|---------|---------|------------|---------|
| 1 | "总结今天学的" | Mode 1 | Auto 直出 | 生成 learning-notes/ 三层结构 |
| 2 | "这段 FastAPI 代码讲一下，为什么要用 Depends" | Mode 1 | Collaborative | 先确认范围再输出深度讲解 |
| 3 | "复习昨天 JWT 的内容" | Mode 2 | Auto 直出 | 生成测验式复习卡片，不只是重读笔记 |
| 4 | "我学了多少了" | Mode 3 | Auto 直出 | 输出进度仪表盘 + mastery ratio |
| 5 | "帮我准备后端开发面试" | Mode 4 | Collaborative | 生成面试话术 + 模拟提问 |
| 6 | "我的提示词怎么样，怎么问才能得到更好回答" | Mode 5 | Collaborative | 输出提示词评分 + 改前改后对比 |
| 7 | "有什么没整理的笔记吗" | Mode 6 | Collaborative | 扫描未处理会话，建议整理 |
| 8 | "今天学的 React Hooks 和之前学的 Vue composition API 有什么联系" | Mode 7 | Collaborative | 生成交叉引用 + 知识关联图 |
| 9 | "周总结，这周学了什么" | Mode 8 | Auto 直出 | 深度提炼 + 领域覆盖 + 薄弱点 |
| 10 | "检查我的学习健康度" | Mode 9 | Auto 直出 | 遗忘风险 + 领域偏科 + 笔记堆积 |

## 二、不应触发测试（5 个）

| # | 输入语句 | 预期结果 | 原因 |
|---|---------|---------|------|
| 1 | "帮我在这个函数里加个 try-catch" | ❌ 不触发 | 用户还在编码中，不是总结学习 |
| 2 | "review 一下我的 PR" | ❌ 不触发 | 纯代码审查，不涉及学习总结 |
| 3 | "帮我把变量名改成驼峰命名" | ❌ 不触发 | 纯格式化，无学习价值 |
| 4 | "今天天气怎么样" | ❌ 不触发 | 与编程学习无关 |
| 5 | "这个 bug 怎么修" | ❌ 不触发 | 纯 bug 修复，不涉及学习 |

---

## 三、边界测试（3 个）

| # | 输入语句 | 预期行为 | 说明 |
|---|---------|---------|------|
| 1 | "帮我看看这个代码" | Collaborative，先澄清 | 可能是 code review（不触发）也可能是学习讲解（触发 Mode 1），需先问 |
| 2 | "整理一下" | Collaborative，先澄清 | 太模糊，可能指整理笔记（Mode 6）也可能指整理代码（不触发） |
| 3 | "轻量模式，总结一下" + 会话只有改了一行 CSS | light 档但提示跳过 | 会话过于 trivial，即使触发也应建议跳过笔记生成 |

## 验收标准

- 应触发：10/10 正确路由到对应模式
- 不应触发：5/5 不触发或给出不匹配提示
- 边界：3/3 正确进入 Collaborative 澄清流程
- 深度档位：4/4 按预期跳 phase
- 状态机：3/3 正确写入和更新 frontmatter
- 多工具：至少 3 个工具正常触发
