     # 客户端表单校验（正则表达式）

> 知识卡片 — 可跨主题复用
> 标签：`javascript` `正则表达式` `前端安全`

---

## 是什么

在用户提交表单前，用 JavaScript 验证输入是否符合预期格式（邮箱、密码、用户名等），不合格时给出明确提示，避免无效数据发送到后端。

## 核心原理

```javascript
function validateEmail(email) {
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}
```

- `^` — 字符串开头
- `[^\s@]+` — 一个或多个非空格、非@字符
- `@` — 必须有一个 @
- `[^\s@]+\.[^\s@]+` — @ 后面是域名部分
- `$` — 字符串结尾

## 常见校验规则

| 场景 | 正则/方法 |
|------|----------|
| 邮箱 | `/^[^\s@]+@[^\s@]+\.[^\s@]+$/` |
| 密码强度 | `length >= 8` + `/[a-zA-Z]/.test()` + `/\d/.test()` |
| 手机号 | `/^1[3-9]\d{9}$/` |
| 非空 | `input.value.trim() !== ""` |

## 易错点

- 正则不加 `^` `$` 会部分匹配——`""@xxx"@yyy.com"` 也会通过
- 校验在前端不能替代后端，攻击者可以绕过前端直接发请求
- 复杂校验（如密码强度规则）应给用户明确的提示文字
